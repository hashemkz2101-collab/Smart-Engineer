# Smart Engineer

Smart Engineer is a proposed bilingual (Persian/English) web platform for
building-project design, engineering coordination, quantity takeoff, estimating,
and project documentation in Iran.

## Repository status

This repository currently contains the product specification and documentation
foundation only. **Application implementation has not started.** Every roadmap
phase and registered feature is marked **NOT STARTED**.

## Documentation

- [`SMART_ENGINEER_MASTER_SPEC.md`](SMART_ENGINEER_MASTER_SPEC.md) is the
  product-scope source of truth.
- [`docs/ROADMAP.md`](docs/ROADMAP.md) defines the gated Phase 0–10 roadmap.
- [`docs/PHASE_STATUS.md`](docs/PHASE_STATUS.md) records phase status.

## Development

No application source code or dependency setup is present yet. Before any
implementation, follow the master specification and documentation maintenance
policy, confirm the active phase and its prerequisites, and obtain resolution
of decisions that block the intended scope. Do not treat proposed architecture
choices as approved.
